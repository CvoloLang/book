# Code and sources

This chapter covers renderer features for code-heavy documentation: executable-looking examples, inputs and outputs, diffs, tabs, file trees, source links, and Go To Definition.

Use these features when they make an explanation easier to scan or verify. Keep the Markdown readable on GitHub and prefer plain prose when a special block would not add clarity.

## Topics

- code blocks, program input, and output;
- diffs and highlighted lines;
- code tabs;
- file trees;
- source links and Go To Definition.
