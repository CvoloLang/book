# Chapter 2. Language Basics

This chapter introduces fundamental programming concepts and how they work in Cvolo. Variables, data types, and operations on values are common to nearly all programming languages, but each language defines its own rules for using them. Here, we focus on the conventions and behavior of Cvolo.

You'll learn about variable declarations and mutability, built-in types, literals, arithmetic and logical operators, assignment, and arrays. These foundations will support the topics that follow, including control flow, functions, and more advanced language features.
