# Chapter 3. Control Flow

The ability to execute code depending on a condition, and to repeat actions while a condition remains true, is fundamental to most programming languages.

In Cvolo, conditional statements and loops let you control the flow of a program. They allow you to choose which statements to execute, repeat actions, and change the usual order of execution.

In this chapter, we'll explore `if` and `else`, the `for` and `while` loops, the `break` and `continue` statements, and an introduction to `switch`.
