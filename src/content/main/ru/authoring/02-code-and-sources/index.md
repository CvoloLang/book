# Код и исходники

Эта глава описывает возможности рендера для документации с большим количеством кода: примеры, ввод и вывод, diff-блоки, вкладки, деревья файлов, ссылки на исходники и Go To Definition.

Используйте эти возможности там, где они делают объяснение проще для чтения или проверки. Markdown всё равно должен оставаться понятным на GitHub, а специальный блок не должен заменять обычное пояснение.

## Темы

- блоки кода, ввод и вывод программы;
- diff и выделение строк;
- вкладки кода;
- деревья файлов;
- ссылки на исходники и Go To Definition.
