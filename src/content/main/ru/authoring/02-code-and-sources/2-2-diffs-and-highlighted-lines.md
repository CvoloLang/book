# 2.2 Diff и выделение строк

Бывают ситуации, когда в статье важно сразу показать небольшое изменение в коде или обратить внимание читателя только на определённые строки и фрагменты. Для этого в Cvolo Docs есть несколько отдельных механизмов: `diff` и `diff-cvolo` для сравнения изменений, `highlight` для выделения целых строк, а также `mark` и `mark-range` для выделения отдельных фрагментов внутри строки.

Diff имеет два режима. Обычный `diff` показывает изменение в привычном формате Git и не зависит от языка кода. `diff-cvolo` — вариант для Cvolo-кода: он сохраняет подсветку синтаксиса Cvolo, а добавленные и удалённые строки задаются служебными комментариями.

## Обычный diff и diff для Cvolo

Разницу проще увидеть на одном и том же изменении.

В обычном `diff` добавленные и удалённые строки обозначаются настоящими `+` и `-` в начале строки:

````markdown
```diff
 public int Sum(int a, int b, int c) {
-    return a + b;
+    return a + b + c;
 }
```

```diff-cvolo
public int Sum(int a, int b, int c) {
    return a + b; // [!code --]
    return a + b + c; // [!code ++]
}
```
````

В `diff-cvolo` служебные комментарии не являются частью отображаемого кода. Cvolo Docs удаляет их перед подсветкой синтаксиса и использует только для оформления добавленных и удалённых строк.

```diff Tab="Diff"
 public int Sum(int a, int b, int c) {
-    return a + b;
+    return a + b + c;
 }
```

```diff-cvolo Tab="Diff Cvolo"
public int Sum(int a, int b, int c) {
    return a + b; // [!code --]
    return a + b + c; // [!code ++]
}
```

Используйте `diff`, когда нужен привычный вид сравнения с `+` и `-`. Используйте `diff-cvolo`, когда важно сохранить подсветку синтаксиса Cvolo.

## Служебные комментарии в diff-cvolo

Комментарий можно поставить в конце изменённой строки:

```cvolo
oldCall(); // [!code --]
newCall(); // [!code ++]
```

`// [!code --]` помечает строку как удалённую, а `// [!code ++]` — как добавленную.

Комментарий также можно вынести на отдельную строку. В этом случае он применяется к следующей строке кода и сам не отображается:

````markdown
```diff-cvolo
// [!code --]
total = Normalize(total);
// [!code ++]
total = Clamp(total);

var y = y
    + x;
```
````

После обработки служебные строки исчезают:

```diff-cvolo
// [!code --]
total = Normalize(total);
// [!code ++]
total = Clamp(total);

var y = y
    + x;
```

Так `diff-cvolo` не конфликтует с настоящими операторами `+` и `-`. Например, `    + x;` в многострочном выражении остаётся обычной частью Cvolo-кода и не воспринимается как обозначение добавленной строки.

При Copy в буфер попадает чистый Cvolo-код без `// [!code ...]`.

## Выделение целых строк

Если в примере нужно обратить внимание на несколько конкретных строк, добавьте `highlight="..."` после языка блока кода.

Значение состоит из номеров строк и диапазонов, разделённых запятыми. Например, `highlight="2,4-5"` выделит строку 2 и строки с 4 по 5. Отсчёт начинается с единицы независимо от того, показаны ли номера строк.

Например:

````markdown
```cvolo lines highlight="2,4-5"
var result = Parse(text);
if (result is Ok(value)) {
    Console.WriteLine(value);
} else {
    Console.WriteLine("parse error");
}
```
````

Выделяются только указанные строки:

```cvolo lines highlight="2,4-5"
var result = Parse(text);
if (result is Ok(value)) {
    Console.WriteLine(value);
} else {
    Console.WriteLine("parse error");
}
```

`highlight` и `lines` независимы друг от друга: строки можно выделять без отображения их номеров, а номера строк можно показывать без выделения.

Для выделения целых строк также поддерживается алиас `highlight-lines`, но в новых статьях лучше использовать `highlight`.

## Выделение фрагментов внутри строки

Если нужно выделить не всю строку, а конкретное слово или часть выражения, используйте `mark` или `mark-range`.

### Выделение по тексту

`mark="..."` выделяет все точные совпадения указанного текста. Сопоставление чувствительно к регистру.

Несколько фрагментов можно перечислить через `|`:

````markdown
```cvolo mark="Ok|Err"
public union Result<T, E> {
    T Ok;
    E Err;
}
```
````

В результате выделяются только `Ok` и `Err`:

```cvolo mark="Ok|Err"
public union Result<T, E> {
    T Ok;
    E Err;
}
```

`mark` удобен, когда нужный фрагмент однозначно находится по самому тексту.

### Выделение точного диапазона

Если одинаковая последовательность символов встречается в строке несколько раз или нужно выделить строго определённый участок, используйте `mark-range`.

Формат одного диапазона:

```text
строка:начало:конец
```

Номер строки начинается с `1`. Позиции `начало` и `конец` считаются с `0`, при этом позиция `конец` не входит в выделение. Несколько диапазонов разделяются символом `|`.

Например, в двух путях можно выделить только сегменты `en` и `ru`:

````markdown
```text mark-range="1:17:19|2:17:19"
src/content/main/en/book/01-introduction/1-1-hello-world.md
src/content/main/ru/book/01-introduction/1-1-hello-world.md
```
````

Результат:

```text mark-range="1:17:19|2:17:19"
src/content/main/en/book/01-introduction/1-1-hello-world.md
src/content/main/ru/book/01-introduction/1-1-hello-world.md
```

Здесь `mark-range` нужен именно для точного выбора позиции: обычный поиск по `en` мог бы затронуть такую же последовательность символов в другой части строки.

Используйте `highlight` для целых строк, `mark` для конкретного текста и `mark-range`, когда важна точная позиция фрагмента.
