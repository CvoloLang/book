# S3. `System.Environment`

`System.Environment` — область hosted Std для API, связанных с процессом и окружением выполнения. Она относится к System, а не к Base.

Эта страница фиксирует границу namespace и намеренно не придумывает члены, которых ещё нет в опубликованном публичном API.

## Доступность

Namespace доступен только при включённом hosted System resolution. Freestanding-код не должен от него зависеть.
