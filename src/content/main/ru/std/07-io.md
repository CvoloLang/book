# S4. `System.IO`

`System.IO` — область стандартной библиотеки для hosted ввода/вывода. Это дочерний namespace, поэтому он подключается отдельно либо используется через полное имя.

```cvolo
using System.IO;
```

Конкретные публичные типы документируются по мере стабилизации; эта страница не выдумывает file/stream API, которого ещё нет в публичном surface.
