# S5. `System.Collections`

`System.Collections` — namespace Std для библиотечных коллекций поверх языковых массивов и slices.

Массивы и slices остаются конструкциями языка/SDK. Hosted collection types относятся сюда только после появления в стабильном публичном API.

Поэтому эта страница пока фиксирует область ответственности без выдуманных классов.
