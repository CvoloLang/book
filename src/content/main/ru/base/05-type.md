# `Type`

`Type` — базовый descriptor типа, который возвращает оператор `typeof(...)`. Сам `typeof` относится к языку, а тип значения, которое он возвращает, объявлен в Base.

Это позволяет работать с type metadata без подключения `System`.

## Базовое использование

```cvolo
Type integerType = typeof(int);
Type stringType = typeof(string);
```

`typeof(T)` не создаёт объект `T` и не вызывает его конструктор. Оператор получает описание самого типа.

## `Type` доступен всегда

Для этого кода не нужен `using System;`:

```cvolo
Type current = typeof(MyStruct);
```

`Type` относится к Base, поэтому остаётся доступным и в freestanding-сборке.

## Язык и Base выполняют разные роли

Важно различать две части конструкции:

| Часть | Где определена |
|---|---|
| `typeof(...)` | язык / compiler syntax |
| `Type` | Base SDK |

Такое разделение позволяет компилятору иметь встроенную семантику `typeof`, но при этом отдавать результат как обычное именованное значение Base API.

## Где применяется

`Type` полезен там, где API или compile-time код должен передать описание типа как значение:

```cvolo
Type elementType = typeof(int);
```

Конкретный набор операций над `Type` должен документироваться вместе с публичным API Base. Эта страница фиксирует базовый контракт: `typeof(...)` возвращает значение типа `Type`, и для этого не требуется System.
