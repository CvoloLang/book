# 2.3 Литералы

Литерал - значение, записанное непосредственно в коде. Например, в `val count = 3;` число `3` является литералом. По записи литерала компилятор может определить его тип.

## Целые числа

Обычный десятичный литерал без суффикса имеет тип `int` при выводе типа:

```cvolo
val x = 0;
val count = 25;
val temperature = -4;
```

Для других целочисленных типов спецификация описывает суффиксы:

| Пример | Выводимый тип |
| --- | --- |
| `42` | `int` |
| `42U` | `uint` |
| `42L` | `long` |
| `42UL` | `ulong` |

```cvolo
val size = 42U;
val distance = 1000L;
val capacity = 1000UL;
```

Буквы суффиксов можно писать в нижнем регистре; для беззнакового `long` допустимы комбинации `UL` и `LU`.

## Дробные числа

Дробные литералы в Cvolo могут иметь тип `float` или `double`. Если суффикс не указан, компилятор выбирает `double`.

| Литерал | Тип |
| --- | --- |
| `2.5` | `double` |
| `2.5f` | `float` |
| `2.5F` | `float` |
| `2.5d` | `double` |

```cvolo
val price = 2.5;          // double
val opacity = 0.75f;     // float
var position = 1.25f;    // float
position = 2.50f;
```

Суффикс `f` особенно важен при работе с функциями, принимающими `float`, например в графических API. Литерал `0.75` без суффикса имеет тип `double`, а `0.75f` - `float`.

Не все дробные десятичные значения точно представимы в двоичном формате. Это справедливо как для `float`, так и для `double`, при этом `double` предоставляет большую точность.

## Логические значения и строки

У типа `bool` есть два литерала: `true` и `false`. Строка записывается в двойных кавычках.

```cvolo
val ready = true;
val finished = false;
val text = "Hello, Cvolo!";
```

Цифра `1` не является заменой `true`. Тип значения проверяется компилятором.

## Символьные литералы

Символьный литерал записывается в одинарных кавычках и имеет тип `char`:

```cvolo
char initial = 'C';
char newline = '\n';
```

В Cvolo `char` имеет размер 8 бит. Для специальных символов используются управляющие последовательности, например `\n` для перевода строки. В отличие от `string`, символьный литерал представляет один байт.

## Литералы и имена переменных

Сравним две записи:

```cvolo
val a = 2;
val b = a;
```

`2` - литерал, а `a` - имя уже объявленной переменной. Значением справа от `=` может быть не только литерал, но и выражение. Как такие выражения вычисляются, рассмотрим дальше.

Здесь намеренно не разбираются специальные строковые формы, системы счисления и экранирование: их действующий синтаксис потребуется отдельно подтвердить по реализации компилятора.
