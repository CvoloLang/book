# 2.7 Побитовые операции

Целые числа хранятся в двоичном виде - как последовательности нулей и единиц. Побитовые операторы позволяют проверять и изменять отдельные биты, не затрагивая остальные. Это полезно, когда несколько независимых признаков или небольших числовых полей нужно хранить в одном числе, например в настройках устройства или заголовке сетевого сообщения.

Для работы с такими данными используют **битовые маски**. Маска - это целое число, единицы в двоичной записи которого указывают на интересующие нас позиции. Например, маска `0b0100` выделяет третий бит справа (нумерация начинается с нуля). С её помощью можно проверить этот бит, установить его в `1` или сбросить в `0`.

## Побитовые операторы

| Оператор | Действие |
| --- | --- |
| `&` | Побитовое И: бит результата равен `1`, если оба соответствующих бита равны `1` |
| `\|` | Побитовое ИЛИ: бит результата равен `1`, если хотя бы один из соответствующих битов равен `1` |
| `^` | Исключающее ИЛИ: бит результата равен `1`, если соответствующие биты различаются |
| `~` | Побитовое НЕ: меняет каждый `0` на `1`, а каждый `1` на `0` |

Рассмотрим числа `12` (`1100` в двоичной записи) и `10` (`1010`):

| Операция | Поразрядное вычисление | Результат |
| --- | --- | --- |
| `12 & 10` | `1100 & 1010 = 1000` | `8` |
| `12 \| 10` | `1100 \| 1010 = 1110` | `14` |
| `12 ^ 10` | `1100 ^ 1010 = 0110` | `6` |
| `~12` | `...00001100` → `...11110011` | `-13` |

В строке с `~` показаны только последние восемь битов. Оператор применяется к одному числу и изменяет **все 32 бита** значения `int`, поэтому `~12` даёт `-13`, а не результат инверсии только четырёх младших битов.

Операторы `&` и `|` встречались и при работе с `bool` в разделе [2.5 «Сравнения и логические выражения»](2-5-comparisons-and-logic.md). Здесь они применяются к целым числам и обрабатывают каждый бит отдельно.

## Сдвиги битов

Сдвиг перемещает биты числа на указанное количество позиций:

| Оператор | Действие | Пример |
| --- | --- | --- |
| `<<` | Сдвиг влево, освободившиеся позиции заполняются нулями | `3 << 2` даёт `12` (`0011` → `1100`) |
| `>>` | Сдвиг вправо с сохранением знака для отрицательных чисел | `12 >> 2` даёт `3` |
| `>>>` | Сдвиг вправо с заполнением старших позиций нулями | `12 >>> 2` даёт `3` |

Для неотрицательных чисел `>>` и `>>>` часто дают одинаковый результат. Различие видно на отрицательных значениях: `>>` сохраняет знаковый бит, а `>>>` заполняет освободившиеся позиции нулями. Например, для 32-битного `int` выражения `-8 >> 1` и `-8 >>> 1` дают `-4` и `2147483644` соответственно.

Сдвиг `1 << n` особенно удобен для создания маски с единственной единицей в позиции `n`.

## Пример: хранение состояния устройства

Предположим, устройство передаёт состояние одним целым числом. В трёх младших битах хранятся признаки подключения, возможности записи и ошибки, а в битах с четвёртого по седьмой - приоритет от `0` до `15`. Таким образом, несколько полей помещаются в одном значении.

```cvolo
using System;

int main()
{
    // Маски для трёх независимых признаков.
    val onlineMask = 1 << 0;    // 0000 0001
    val writableMask = 1 << 1;  // 0000 0010
    val errorMask = 1 << 2;     // 0000 0100

    // Приоритет занимает четыре бита, начиная с позиции 4.
    val priorityShift = 4;
    val priorityMask = 0b1111;

    // Устройство подключено, запись разрешена, приоритет равен 5.
    // 5 << 4 = 0101 0000; объединяем поля через побитовое ИЛИ.
    var status = onlineMask | writableMask | (5 << priorityShift);
    Console.WriteLine(status); // 83

    // Проверяем отдельные признаки с помощью маски.
    Console.WriteLine((status & onlineMask) != 0); // 1: подключено
    Console.WriteLine((status & errorMask) != 0);  // 0: ошибки нет

    // Сдвигаем поле приоритета вправо и оставляем только четыре бита.
    val priority = (status >> priorityShift) & priorityMask;
    Console.WriteLine(priority); // 5

    // Устанавливаем признак ошибки, не меняя остальные поля.
    status |= errorMask;
    Console.WriteLine(status); // 87

    // Снимаем разрешение на запись, сохраняя остальные биты.
    status &= ~writableMask;
    Console.WriteLine(status); // 85

    return 0;
}
```

```output
83
1
0
5
87
85
```

В примере `|` объединяет значения нескольких полей, `&` выделяет нужные биты, а `~` помогает снять один признак, не затронув остальные. Сдвиги `<<` и `>>` позволяют размещать числовое поле в отведённых позициях и извлекать его обратно.

Для изменения отдельных битов также можно использовать `^`: эта операция переключает выбранные биты с `0` на `1` и обратно. В отличие от установки через `|`, повторное применение `^` с той же маской вернёт исходное состояние.
