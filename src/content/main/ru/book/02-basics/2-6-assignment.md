# 2.6 Присваивание и изменение значения

В статье о переменных мы рассмотрели, как `var` позволяет изменять значение после объявления. Теперь разберём обычное присваивание, его сокращённые формы и операции увеличения и уменьшения числовых значений на единицу.

## Присваивание

Оператор `=` записывает значение выражения справа в изменяемую переменную слева:

```cvolo
var points = 2;
points = 3;
```

После второй инструкции значение `points` равно `3`. Тип переменной при этом не меняется.

Переменной, объявленной через `val`, нельзя присвоить новое значение после инициализации:

```cvolo tab="Недопустимое присваивание" lines highlight="2"
val points = 2;
points = 3;
```

Компилятор отклонит строку 2, поскольку `points` - неизменяемая переменная.

## Составное присваивание

Составные операторы объединяют вычисление и присваивание в одну запись. Вместо `total = total + 5;` можно написать `total += 5;`: текущее значение `total` складывается с `5`, а результат сохраняется в ту же переменную.

```cvolo
var total = 10;
total += 5; // 15
total *= 2; // 30
total -= 3; // 27
```

### Операторы присваивания в Cvolo

В таблице показаны сокращённые операторы и соответствующие им полные записи для обычной переменной `x`.

| Оператор | Сокращённая запись | Полная запись | Действие |
| --- | --- | --- | --- |
| `=` | `x = y;` | `x = y;` | Присваивание |
| `+=` | `x += y;` | `x = x + y;` | Сложение |
| `-=` | `x -= y;` | `x = x - y;` | Вычитание |
| `*=` | `x *= y;` | `x = x * y;` | Умножение |
| `/=` | `x /= y;` | `x = x / y;` | Деление |
| `%=` | `x %= y;` | `x = x % y;` | Остаток от деления |
| `&=` | `x &= y;` | `x = x & y;` | Побитовое И |
| `\|=` | `x \|= y;` | `x = x \| y;` | Побитовое ИЛИ |
| `^=` | `x ^= y;` | `x = x ^ y;` | Исключающее ИЛИ |
| `<<=` | `x <<= y;` | `x = x << y;` | Сдвиг влево |
| `>>=` | `x >>= y;` | `x = x >> y;` | Арифметический сдвиг вправо |
| `>>>=` | `x >>>= y;` | `x = x >>> y;` | Логический сдвиг вправо |

Доступность каждой операции зависит от типов операндов. Арифметические операторы применяются к совместимым числовым значениям, а сдвиги - к целочисленным. Составные операторы с `&` и `|` также могут использоваться с логическими значениями. Побитовые операции и сдвиги подробно рассматриваются в разделе [2.7 «Побитовые операции»](2-7-bitwise-operations.md).

Записи в таблице поясняют результат операции для обычной переменной. При присваивании полям, элементам массивов и другим более сложным выражениям слева могут иметь значение особенности вычисления этой части выражения.

## Инкремент (`++`) и декремент (`--`)

Операторы `++` и `--` увеличивают или уменьшают значение изменяемой числовой переменной на единицу. Каждый из них можно записать **перед переменной** (префиксная форма) или **после неё** (постфиксная форма).

Само значение переменной изменяется в обоих случаях. Различие возникает, когда **результат операции используется в другом выражении**:

- **Префиксная форма** (`++i`, `--i`) изменяет переменную и передаёт в выражение её **новое** значение.
- **Постфиксная форма** (`i++`, `i--`) тоже изменяет переменную, но передаёт в выражение значение, которое было **до изменения**.

| Форма | Значение выражения при исходном `i = 10` | Значение `i` после операции |
| --- | --- | --- |
| `++i` | 11 | 11 |
| `i++` | 10 | 11 |
| `--i` | 9 | 9 |
| `i--` | 10 | 9 |

### Когда важна форма записи

Предположим, программа последовательно выдаёт номера заявкам. Переменная `nextNumber` хранит номер, который нужно выдать следующей заявке. Постфиксный инкремент позволяет одновременно получить этот номер и подготовить следующий:

```cvolo
var nextNumber = 100;
val assignedNumber = nextNumber++;
// assignedNumber = 100, nextNumber = 101
```

Если переменная хранит **последний выданный** номер, сначала нужно увеличить его, а затем использовать полученное значение. Для этого подходит префиксный инкремент:

```cvolo
var lastNumber = 99;
val assignedNumber = ++lastNumber;
// assignedNumber = 100, lastNumber = 100
```

Таким образом, выбор формы зависит от того, какое значение требуется получить: **до изменения переменной или после него**. То же правило действует для `--`.

Проверим разницу на примере программы:

```cvolo
using System;

int main()
{
    var prefixValue = 10;
    val prefixResult = ++prefixValue;

    Console.WriteLine(prefixResult);
    Console.WriteLine(prefixValue);

    var postfixValue = 10;
    val postfixResult = postfixValue++;

    Console.WriteLine(postfixResult);
    Console.WriteLine(postfixValue);
    return 0;
}
```

```output
11
11
10
11
```

Когда результат операции не используется, обе формы дают одинаковый итог:

```cvolo
var index = 0;
index++; // 1
++index; // 2
index--; // 1
--index; // 0
```
