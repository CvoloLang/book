# 2.4 Арифметические операции

Выражение вычисляет значение. Например, `2 + 3` даёт `5`. В Cvolo арифметические выражения составляются из чисел, переменных, скобок и операторов.

## Основные операторы

| Оператор | Что делает | Пример |
| --- | --- | --- |
| `+` | Складывает | `2 + 3` |
| `-` | Вычитает | `7 - 2` |
| `*` | Умножает | `4 * 3` |
| `/` | Делит | `8 / 2` |
| `%` | Находит остаток от деления | `8 % 3` |

```cvolo
val width = 4;
val height = 3;
val area = width * height; // 12
val perimeter = (width + height) * 2; // 14
```

Значения `width` и `height` не меняются: результат каждого выражения сохраняется в новой переменной.

## Приоритет операций

Умножение и деление выполняются раньше сложения и вычитания. Скобки позволяют задать нужный порядок:

```cvolo
val first = 2 + 3 * 4;   // 14
val second = (2 + 3) * 4; // 20
```

В первом выражении сначала вычисляется `3 * 4`. Во втором скобки требуют сперва сложить `2` и `3`.

## Остаток от деления

Оператор `%` полезен, когда нужно узнать остаток:

```cvolo
val remainder = 8 % 3; // 2
```

Это результат вычисления с целыми положительными числами: `3` помещается в `8` два раза, остаётся `2`.

## Типы операндов

```cvolo
val a = 2;
val b = 3;
val sum = a + b;
```

Оба числа здесь имеют тип `int`, поэтому результат также можно использовать как целое число. Не стоит автоматически считать, что любая комбинация `int`, `uint` и `double` разрешена. При смешении типов компилятор проверяет доступные операции и правила преобразования.
