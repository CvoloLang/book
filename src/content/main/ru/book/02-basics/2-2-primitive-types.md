# 2.2 Встроенные типы

У каждого значения в Cvolo есть тип. Он определяет, какие данные можно хранить в переменной и какие операции над ними допустимы. Тип проверяется компилятором независимо от того, объявлена переменная с помощью `val` или `var`.

В Cvolo предусмотрены следующие встроенные типы и специальные обозначения:

| Категория | Типы |
| --- | --- |
| Целые числа со знаком | `sbyte`, `short`, `int`, `long`, `nint` |
| Целые числа без знака | `byte`, `ushort`, `uint`, `ulong`, `nuint` |
| Числа с плавающей точкой | `float`, `double` |
| Логические значения | `bool` |
| Символы и строки | `char`, `string` |
| Специальные обозначения | `void`, `null` |

`void` и `null` имеют особое назначение. Они не используются для хранения обычных значений, как `int`, `bool` или `string`.

## Вывод типа

Если тип не указан в объявлении, компилятор определяет его по выражению инициализации:

```cvolo
val count = 2;                 // int
var ratio = 1.5;               // double
val enabled = true;            // bool
val greeting = "Hello, Cvolo!"; // string
```

Вывод типа выполняется при компиляции. `var` разрешает изменять значение переменной, но не превращает её в переменную с произвольным типом.

## Явное указание типа

Тип можно указать непосредственно в объявлении:

```cvolo
int count = 2;
var int attempts = 3;
```

В обоих случаях тип - `int`. Переменная `count` неизменяемая по умолчанию, а `attempts` объявлена изменяемой с помощью `var`. **Тип** и **изменяемость** - независимые характеристики объявления.

| Объявление | Определение типа | Изменяемость |
| --- | --- | --- |
| `val x = 2;` | Выводится из выражения | Неизменяемая |
| `var x = 2;` | Выводится из выражения | Изменяемая |
| `int x = 2;` | Указан явно | Неизменяемая |
| `var int x = 2;` | Указан явно | Изменяемая |

## Целочисленные типы

Целочисленные типы различаются разрядностью и диапазоном представимых значений. В таблице они расположены по возрастанию максимального значения. Указанные границы диапазонов включены.

| Тип | Разрядность | Диапазон значений |
| --- | --- | --- |
| `sbyte` | 8 бит | от -128 до 127 |
| `byte` | 8 бит | от 0 до 255 |
| `short` | 16 бит | от -32 768 до 32 767 |
| `ushort` | 16 бит | от 0 до 65 535 |
| `int` | 32 бита | от -2 147 483 648 до 2 147 483 647 |
| `uint` | 32 бита | от 0 до 4 294 967 295 |
| `long` | 64 бита | от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 |
| `ulong` | 64 бита | от 0 до 18 446 744 073 709 551 615 |

```cvolo
int temperature = -10;
uint items = 12U;
long distance = 100000L;
```

Литералы с суффиксами `U` и `L` позволяют явно выбрать `uint` или `long`. Их синтаксис рассматривается в следующей статье.

## Числа с плавающей точкой

Для представления дробных чисел предусмотрены два типа:

| Тип | Размер | Точность |
| --- | --- | --- |
| `float` | 32 бита | Одинарная |
| `double` | 64 бита | Двойная |

```cvolo
float red = 0.25f;
float green = 0.50f;
float blue = 0.75f;

val opacity = 1.0f;     // float
val temperature = 22.5; // double
```

Суффикс `f` указывает, что дробный литерал имеет тип `float`. Без суффикса такой литерал имеет тип `double`. Различие важно, в частности, при передаче данных в графические API: многие функции OpenGL принимают именно 32-битные числа с плавающей точкой.

## Логические значения, символы и строки

| Тип | Назначение |
| --- | --- |
| `bool` | Логическое значение `true` или `false` |
| `char` | Один 8-битный символ (байт) |
| `string` | Строка текста в кодировке UTF-8 |

```cvolo
val success = true;
char initial = 'C';
val message = "Hello, Cvolo!";
```

`char` представляет один байт, а не произвольный символ Unicode. Например, строку из нескольких символов следует хранить в `string`. Запись символьных и строковых литералов рассматривается в следующей статье.

## Совместимость типов

После объявления переменной её тип остаётся определённым. Изменяемость разрешает присвоить другое **совместимое значение**, но не произвольно заменить тип:

```cvolo tab="Допустимо"
var points = 2;
points = 3;
```

```cvolo tab="Несовместимый тип" lines highlight="2"
var points = 2;
points = "three"; // ERROR: string несовместим с int
```

## Целые числа платформенной разрядности

Типы `nint` (со знаком) и `nuint` (без знака) отличаются от `int` и `uint` тем, что их размер зависит от **целевой архитектуры**, для которой собирается программа.

Разрядность определяет диапазон значений `nint` и `nuint`:

| Тип | Целевая архитектура | Разрядность | Диапазон значений |
| --- | --- | --- | --- |
| `nint` | x86 | 32 бита | от -2 147 483 648 до 2 147 483 647 |
| `nuint` | x86 | 32 бита | от 0 до 4 294 967 295 |
| `nint` | x64 | 64 бита | от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 |
| `nuint` | x64 | 64 бита | от 0 до 18 446 744 073 709 551 615 |

Для сравнения — размеры обычного `int` и платформозависимых типов:

| Целевая архитектура | `int` | `nint` | `nuint` |
| --- | --- | --- | --- |
| x86 (32-разрядная) | 4 байта | 4 байта | 4 байта |
| x64 (64-разрядная) | 4 байта | 8 байт | 8 байт |

Размер типа можно получить с помощью `sizeof<T>()`:

```cvolo
nuint integerSize = sizeof<int>();      // 4 байта на x86 и x64
nuint nativeSize = sizeof<nint>();      // 4 байта на x86, 8 байт на x64
nuint unsignedSize = sizeof<nuint>();   // 4 байта на x86, 8 байт на x64
```

Все три выражения возвращают значение типа `nuint`. Размер определяется архитектурой **собранной программы**, а не просто разрядностью установленной операционной системы. Например, 32-разрядная программа на 64-разрядной системе использует 32-разрядные `nint` и `nuint`.

## `void` и `null`

`void` и `null` используются в языке по-разному:

- **`void`** указывается в объявлении функции, которая не возвращает значение.
- **`null`** - специальный литерал, обозначающий отсутствие значения. Его можно использовать только в тех выражениях и объявлениях, где это допускает соответствующий тип и правила языка.

`null` не является универсальной заменой значений других типов. В частности, нельзя считать, что любая переменная допускает присваивание `null`. Само слово `null` также не используют вместо типа переменной при её объявлении.
