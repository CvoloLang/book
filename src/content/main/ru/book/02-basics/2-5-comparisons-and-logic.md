# 2.5 Сравнения и логические выражения

Операторы сравнения позволяют определить, равны ли значения или является одно значение большим, чем другое. Если проверяемое условие выполняется, выражение принимает значение `true`, в противном случае - `false`. Полученное логическое значение можно использовать в других выражениях, условиях и циклах.

## Операции сравнения

| Оператор | Значение |
| --- | --- |
| `==` | Равно |
| `!=` | Не равно |
| `<` | Меньше |
| `>` | Больше |
| `<=` | Меньше или равно |
| `>=` | Больше или равно |

```cvolo
val score = 72;
val passed = score >= 60;      // true
val perfect = score == 100;    // false
```

`=` используется для присваивания значения, а `==` - для сравнения на равенство.

## Логическое НЕ

Оператор `!` изменяет логическое значение на противоположное:

```cvolo
val blocked = false;
val allowed = !blocked; // true
```

## Логическое И и ИЛИ

Логические операции позволяют объединять несколько проверок. Оператор `&&` (И) даёт `true`, только если оба операнда истинны. Для оператора `||` (ИЛИ) достаточно, чтобы хотя бы один операнд был истинным.

Ниже приведены результаты всех сочетаний двух логических значений. Для компактности `0` обозначает `false`, а `1` - `true`. В коде Cvolo логические значения записываются как `false` и `true`.

| `value1` | `value2` | `&&` (И) | `\|\|` (ИЛИ) |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 0 |
| 0 | 1 | 0 | 1 |
| 1 | 0 | 0 | 1 |
| 1 | 1 | 1 | 1 |

Для типа `bool` существуют также одиночные операторы `&` (И) и `|` (ИЛИ). Они дают те же логические результаты, что и `&&` и `||` соответственно, но отличаются правилами вычисления правого операнда.

### Пример проверки доступа

Предположим, пользователь пытается открыть административный раздел приложения. Для доступа необходимо, чтобы он **вошёл в систему** и **имел соответствующие права**. Если хотя бы одно из условий не выполнено, доступ должен быть запрещён. В примере результаты этих проверок заданы заранее; в реальном приложении они определялись бы при обработке запроса пользователя.

```cvolo
using System;

int main()
{
    val isAuthenticated = true;
    val hasPermission = false;

    Console.WriteLine(isAuthenticated && hasPermission);
    Console.WriteLine(!isAuthenticated || !hasPermission);
    Console.WriteLine(isAuthenticated & hasPermission);
    Console.WriteLine(!isAuthenticated | !hasPermission);

    return 0;
}
```
```output
0
1
0
1
```

Пользователь вошёл в систему, но у него нет необходимых прав. Поэтому первая проверка возвращает `false` (`0`), а вторая подтверждает необходимость отказать в доступе - `true` (`1`). Последние две строки выполняют аналогичные проверки с одиночными `&` и `|`: результат остаётся тем же, но правила вычисления правого операнда отличаются.

## Вычисление правого операнда

Одиночные и двойные логические операторы отличаются правилами вычисления правой части выражения:

- `&&` - логическое И с коротким замыканием: если левый операнд равен `false`, правая часть не вычисляется.
- `||` - логическое ИЛИ с коротким замыканием: если левый операнд равен `true`, правая часть не вычисляется.
- `&` - логическое И без короткого замыкания: оба операнда вычисляются.
- `|` - логическое ИЛИ без короткого замыкания: оба операнда вычисляются.

Операторы `&` и `|` также применяются к целым числам для побитовых операций. Они рассматриваются отдельно в статье 2.7 «Побитовые операции».
