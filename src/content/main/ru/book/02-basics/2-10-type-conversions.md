# 2.10 Преобразование типов

У каждого значения в Cvolo есть тип. Он определяет, как значение хранится и какие операции с ним допустимы. Иногда программе нужно использовать значение одного типа там, где требуется другой. Для этого существует **преобразование типов**.

Например, целое число можно преобразовать в дробное, а число типа `double` в `float`. Однако не все преобразования сохраняют исходное значение без изменений: при уменьшении разрядности или переходе к целому типу часть данных может потеряться.

## Неявное преобразование

**Неявное преобразование** происходит без специальной записи со стороны программиста, когда Cvolo допускает переход от одного типа к другому.

Например, переменную типа `short` можно использовать для инициализации переменной типа `long`:

```cvolo
short quantity = 120;
long total = quantity;
```

Здесь `quantity` имеет тип `short`, а `total` - `long`. Тип `long` имеет большую разрядность и может хранить любое значение типа `short`, поэтому при преобразовании число `120` сохраняется без изменений. Компилятор выполняет преобразование при инициализации `total`, но тип переменной `quantity` остаётся прежним.

Аналогичным образом значение типа `float` можно использовать при инициализации `double`:

```cvolo
float rate = 1.5f;
double preciseRate = rate;
```

### Преобразования целых чисел и потеря данных

В Cvolo неявные преобразования между целочисленными типами должны сохранять диапазон значений исходного типа. Например, `short` можно преобразовать в `long`, но обратный переход требует явного приведения.

```cvolo tab="Допустимо"
short small = 120;
long large = small;
```

```cvolo tab="Недопустимо" lines highlight="2"
int source = 300;
byte result = source; // Требуется явное приведение
```

Если преобразование может отбросить часть числа, программист должен указать его явно:

```cvolo
int source = 300;
byte result = (byte)source; // 44
```

Число `300` не помещается в 8-битный `byte`. При таком явном преобразовании сохраняются младшие 8 бит, поэтому результат равен `44`. Возможность проверки переполнения при преобразовании рассматривается отдельно и пока не описывается как готовая возможность языка.

Есть исключение для целочисленных литералов: если число сразу записано в объявлении и помещается в целевой тип, приведение не требуется.

```cvolo tab="Допустимо"
byte small = 200;
```

```cvolo tab="Недопустимо" lines highlight="1"
byte small = 300; // Числовой литерал слишком велик для byte
```

Таким образом, при неявных преобразованиях целочисленных переменных компилятор должен учитывать диапазоны их типов. Они приведены в разделе [2.2 «Встроенные типы»](2-2-primitive-types.md).

## Явное преобразование

Если преобразование не выполняется автоматически или программист хочет явно указать необходимый тип, используют **приведение типа**. В Cvolo оно записывается как `(ЖелаемыйТип)выражение`:

```cvolo
int count = 42;
double asDouble = (double)count;
```

Запись `(double)count` означает: взять значение `count` и преобразовать его в `double`. Результат преобразования можно сохранить в переменной, передать в функцию или использовать в другом выражении.

У приведения есть три основные части:

- `(double)` - тип, к которому нужно преобразовать значение;
- `count` - исходное выражение;
- `(double)count` - новое выражение, результат которого имеет тип `double`.

Исходная переменная `count` остаётся переменной типа `int`: преобразуется **значение выражения**, а не тип уже объявленной переменной.

## Преобразования между целыми и дробными числами

Целое число можно явно преобразовать в `float` или `double`:

```cvolo
int items = 12;
double itemsAsDouble = (double)items;
```

Обратное преобразование тоже возможно, но у него есть важная особенность: при преобразовании дробного числа в целое **дробная часть отбрасывается, без округления**. Например, `8.75` превращается в `8`, а не в `9`.

```cvolo
double positive = 8.75;
double negative = -8.75;

int first = (int)positive; // 8
int second = (int)negative; // -8
```

В обоих случаях отбрасывание происходит **в сторону нуля**: `8.75` становится `8`, а `-8.75` становится `-8`, не `-9`. Это отличается от обычного округления до ближайшего целого и от округления в меньшую сторону. Примеры предполагают, что исходные значения находятся в диапазоне целевого целочисленного типа. Поведение для слишком больших чисел и особых дробных значений здесь не рассматривается.

## Преобразования между `float` и `double`

`float` хранит дробное число с меньшей точностью, чем `double`. Поэтому переход от `float` к `double` допускается неявно, а преобразование из `double` в `float` требует явного приведения:

```cvolo tab="Допустимо"
float original = 1.25f;
double expanded = original;
float reduced = (float)expanded;
```

```cvolo tab="Недопустимо" lines highlight="2"
double original = 1.25;
float reduced = original; // Нужно явное приведение
```

Преобразование `double` в `float` может привести к потере точности. Даже если число помещается в диапазон `float`, этот тип не обязательно способен представить его с той же точностью.

Не путайте приведение типа с суффиксом дробного литерала. Записи `1.25` и `1.25f` сразу создают значения разных типов, а `(float)1.25` преобразует уже записанное значение типа `double`. Подробнее о литералах - в разделе [2.3 «Литералы»](2-3-literals.md).

## Пример: разные способы преобразования

В следующей программе используются три преобразования: явное сужение целого числа, преобразование дробного числа в целое и расширение дробного типа.

```cvolo
using System;

int main()
{
    int original = 300;
    byte compact = (byte)original;

    double price = 19.75;
    int wholePrice = (int)price;

    float fraction = 1.25f;
    double expanded = fraction;

    Console.WriteLine(compact);
    Console.WriteLine(wholePrice);
    Console.WriteLine(expanded);

    return 0;
}
```

```output
44
19
1.25
```

В первом случае число `300` преобразуется в 8-битный `byte`, поэтому результат равен `44`. Во втором дробная часть `19.75` отбрасывается. В третьем значение типа `float` преобразуется в `double` без явного приведения.

При преобразовании типов важно различать два вопроса: **разрешает ли компилятор такое преобразование** и **сохранится ли исходное значение без потерь**. Это не всегда одно и то же.
