# 2.8 Массивы

Массив позволяет хранить несколько значений одного типа в определённом порядке. Эти значения называются **элементами массива**. Они располагаются последовательно в памяти, а обратиться к отдельному элементу можно по его **индексу** - номеру позиции в массиве.

Например, вместо трёх отдельных переменных с ценами товаров можно создать один массив и получать нужную цену по её позиции. Индексы начинаются с `0`: у первого элемента индекс `0`, у второго - `1`, у третьего - `2`.

## Создание массива

В Cvolo массив фиксированного размера записывается как `Тип[Размер]`. Размер определяет количество элементов и должен быть известен во время компиляции.

```cvolo
var int[3] prices = { 120, 80, 160 };
```

В этом объявлении:

- `int` - тип каждого элемента;
- `[3]` - количество элементов;
- `{ 120, 80, 160 }` - начальные значения в порядке их расположения.

Массив `prices` содержит три элемента:

| Индекс | `0` | `1` | `2` |
| --- | --- | --- | --- |
| Значение | `120` | `80` | `160` |

Число элементов фиксируется при создании массива: нельзя добавить четвёртый элемент или изменить его размер. Размер входит и в тип массива, поэтому `int[3]` и `int[4]` - разные типы.

## Обращение к элементам

Чтобы прочитать значение элемента, после имени массива указывают индекс в квадратных скобках:

```cvolo
val firstPrice = prices[0];  // 120
val lastPrice = prices[2];   // 160
```

Индексом может быть не только число, записанное непосредственно в коде, но и выражение с целочисленным значением. Это позволяет выбирать элемент во время выполнения программы.

## Изменяемость массива

Как и обычная переменная, массив может быть изменяемым или неизменяемым. **Если при объявлении не указан `var`, массив неизменяемый по умолчанию**. Это относится и к его элементам:

- `var` - значения элементов можно изменять по индексу;
- `val` или объявление без `var` - элементы можно читать, но изменять их значения нельзя.

```cvolo tab="Изменяемый массив" lines highlight="2"
var int[3] prices = { 120, 80, 160 };
prices[1] = 90; // Допустимо: теперь второй элемент равен 90
```

```cvolo tab="Неизменяемый массив" lines highlight="2"
int[3] prices = { 120, 80, 160 };
prices[1] = 90; // Недопустимо: var не указан
```

Записи `int[3] prices = { 120, 80, 160 };` и `val int[3] prices = { 120, 80, 160 };` **эквивалентны**: обе объявляют неизменяемую переменную типа `int[3]`. Если тип указан явно, `val` можно опустить. Как и у других переменных, тип и изменяемость массива независимы - это правило описано в разделе [2.2 «Встроенные типы»](2-2-primitive-types.md). Размер массива остаётся фиксированным независимо от изменяемости. Подробнее об изменяемости переменных - в разделе [2.1 «Переменные и изменяемость»](2-1-variables-and-mutability.md).

## Пример: цены товаров

В программе хранятся цены трёх товаров. Затем цена второго товара изменяется, а общая стоимость вычисляется по элементам массива.

```cvolo
using System;

int main()
{
    var int[3] prices = { 120, 80, 160 };

    Console.WriteLine(prices[0]); // Первый товар: 120
    Console.WriteLine(prices[2]); // Третий товар: 160

    val selectedIndex = 1;
    prices[selectedIndex] = 90;  // Обновляем цену второго товара
    Console.WriteLine(prices[1]);

    val total = prices[0] + prices[1] + prices[2];
    Console.WriteLine(total);

    return 0;
}
```

```output
120
160
90
370
```

Переменная `selectedIndex` содержит индекс элемента, а не его значение: `1` указывает на второй товар, цена которого после присваивания становится равной `90`. Размер массива при этом не меняется.

## Другие способы инициализации

Тип и размер массива можно не указывать, если компилятор способен определить их по значениям в фигурных скобках:

```cvolo
var numbers = { 10, 20, 30 }; // int[3]
```

Когда нужен массив заданного размера, его можно заполнить нулями с помощью пустых фигурных скобок или повторить одно значение для всех элементов:

```cvolo
var int[4] counters = {}; // { 0, 0, 0, 0 }
var int[4] levels(7);    // { 7, 7, 7, 7 }
```

Для пустого списка `{}` тип и размер необходимо указать явно: по отсутствующим элементам компилятор не сможет их определить. При перечислении значений в `{ ... }` количество элементов должно соответствовать объявленному размеру.

## Границы массива

У массива из трёх элементов допустимые индексы - `0`, `1` и `2`. Индекс `3` не указывает на четвёртый элемент: такого элемента нет.

Cvolo проверяет границы при обращении к элементам. Если индекс выходит за допустимый диапазон, программа завершается с ошибкой во время выполнения. Это предотвращает чтение или изменение памяти за пределами массива.

## Массивы и срезы

Записи `int[3]` и `int[]` в Cvolo означают разные вещи:

- `int[3]` - массив из трёх элементов, размер которого известен при компиляции;
- `int[]` - **срез**, позволяющий работать с последовательностью элементов, длина которой может определяться во время выполнения.

Срез представляет уже существующую область памяти и сам по себе не является массивом с изменяемым количеством элементов. Подробно со срезами познакомимся позднее.
