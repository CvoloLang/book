# 2.9 Функции

В предыдущих примерах мы писали код внутри `main()` и вызывали `Console.WriteLine()`. В Cvolo можно объявлять собственные **функции** - именованные блоки кода, выполняющие заданный алгоритм. Функцию можно вызывать из разных мест программы, передавать ей значения и при необходимости получать результат.

Функции помогают не повторять одни и те же инструкции и разделять программу на небольшие, понятные части.

## Объявление и вызов функции

В Cvolo объявление функции можно представить так: `ВозвращаемыйТип НазваниеФункции(ТипВходногоПараметра имяПараметра, ...)`. Перед названием указывают тип возвращаемого значения, в круглых скобках - параметры, а в фигурных скобках - тело функции. Параметры перечисляют через запятую; если их нет, круглые скобки оставляют пустыми. Многоточие здесь условное: оно обозначает дополнительные параметры, а не часть синтаксиса Cvolo.

Рассмотрим функцию, которая принимает два целочисленных значения, перемножает их и возвращает полученный результат:

```cvolo
using System;

int Multiply(int left, int right)
{
    return left * right;
}

int main()
{
    val first = Multiply(3, 4);
    val second = Multiply(5, 6);

    Console.WriteLine(first);
    Console.WriteLine(second);
    return 0;
}
```

```output
12
30
```

Объявление функции состоит из типа возвращаемого значения, имени, списка параметров и **тела функции**. В примере с `Multiply` каждая часть имеет своё назначение:

- `int` перед именем - **тип возвращаемого значения**. Он указывает, что функция возвращает целое число типа `int`;
- `Multiply` - **имя функции**, по которому её можно вызвать из другого места программы;
- `(int left, int right)` - **список параметров** в круглых скобках. У функции два параметра: `left` и `right`. Оба имеют тип `int` и получают значения при вызове;
- `{` и `}` - фигурные скобки, между которыми находится **тело функции**. Его инструкции выполняются при каждом вызове;
- `return left * right;` - инструкция, которая вычисляет произведение параметров, завершает выполнение функции и возвращает результат в место вызова.

Вызов `Multiply(3, 4)` передаёт функции два числа. Она вычисляет их произведение, а инструкция `return` возвращает результат в место вызова. Поэтому переменная `first` получает значение `12`, а `second` - `30`.

Функция `main()` имеет особую роль: с неё начинается выполнение программы. О точке входа мы говорили в разделе [1.1 «Первая программа»](../01-introduction/1-1-hello-world.md).

## Параметры функции и аргументы вызова

**Параметры** - имена, объявленные в круглых скобках после имени функции. Через них функция получает значения для работы. При обычном объявлении каждому параметру необходимо явно указать тип.

**Аргументы** - значения или выражения, которые передают при вызове. Они сопоставляются параметрам по порядку. Например, в вызове `Multiply(3, 4)` число `3` передаётся параметру `left`, а `4` - параметру `right`.

Порядок особенно важен, когда параметры выполняют разные роли:

```cvolo
int Subtract(int left, int right)
{
    return left - right;
}
```

```cvolo
val a = Subtract(10, 3); // 7
val b = Subtract(3, 10); // -7
```

Компилятор проверяет количество аргументов и совместимость их типов с параметрами функции. Например, вызов `Subtract(10)` не подходит к объявлению с двумя параметрами, а `Subtract(10, "3")` передаёт строку вместо целого числа.

Функция может не иметь параметров. В этом случае при объявлении и вызове используют пустые круглые скобки: `GetValue()`.

## Возвращаемое значение и ключевое слово `return`

Тип перед именем функции определяет, какое значение она возвращает. Если указан `int`, результат должен быть совместим с `int`. Инструкция `return` завершает выполнение функции и передаёт значение вызывающему коду.

`return` можно использовать не только в конце функции, но и для **досрочного завершения её выполнения**. Как только программа достигает `return`, она выходит из текущей функции: инструкции, расположенные далее по выполняемому пути, уже не выполняются. Например, функция может завершиться раньше при выполнении определённого условия. Как записывать такие условия, разберём в разделе [3.1 «Условные конструкции `if` и `else`»](../03-control-flow/3-1-if-and-else.md).

Возвращаемое значение можно не только сохранять в переменной, но и использовать в составе выражения:

```cvolo
val result = Multiply(4, 5) + 10; // 30
```

Обычная функция с возвращаемым значением должна содержать соответствующую инструкцию `return`. В `main` запись `return 0;` имеет дополнительный смысл: она сообщает среде выполнения код завершения программы, а не возвращает число другой функции.

## Функции без возвращаемого значения

Если функция выполняет действие и не должна возвращать результат, вместо типа указывают `void`:

```cvolo
void PrintMessage(string message)
{
    Console.WriteLine(message);
}
```

Такую функцию вызывают как отдельную инструкцию:

```cvolo
PrintMessage("Order saved");
```

Здесь функция выводит переданную строку, но не создаёт значение, которое можно было бы присвоить переменной. Функция `void` может завершиться после последней инструкции без `return`. При необходимости для досрочного завершения можно написать `return;` без выражения.

## Локальные переменные и изменяемость параметров

Параметры и переменные, объявленные внутри функции, принадлежат её локальной области видимости. Например, параметры `left` и `right` функции `Multiply` недоступны по этим именам внутри `main`. То же правило действует для локальных переменных, созданных в теле функции.

Обычные параметры в Cvolo **неизменяемы**. Если при вычислении нужно изменять значение, можно создать локальную переменную с помощью `var`:

```cvolo
int NextNumber(int current)
{
    var result = current;
    result++;
    return result;
}
```

Вызов `NextNumber(10)` возвращает `11`. При этом меняется только локальная переменная `result`, а параметр `current` остаётся неизменным.

При передаче обычных целочисленных значений функция получает их значения, а не возможность изменять переменную вызывающего кода. Передачу по ссылке и работу с другими видами данных рассмотрим отдельно, после знакомства с владением и ссылками.

## Пример: расчёт стоимости заказа

Предположим, программа рассчитывает стоимость заказа из цены одного товара, его количества и стоимости доставки. Вычисление вынесем в отдельную функцию, а вывод результата - в другую:

```cvolo
using System;

int CalculateTotal(int unitPrice, int quantity, int deliveryFee)
{
    val productsCost = unitPrice * quantity;
    return productsCost + deliveryFee;
}

void PrintOrder(int unitPrice, int quantity, int deliveryFee)
{
    val total = CalculateTotal(unitPrice, quantity, deliveryFee);
    Console.WriteLine(total);
}

int main()
{
    PrintOrder(120, 3, 40);
    PrintOrder(80, 2, 0);
    return 0;
}
```

```output
400
160
```

При первом вызове `PrintOrder` функция `CalculateTotal` вычисляет `120 * 3 + 40`, при втором - `80 * 2 + 0`. Одна функция отвечает за расчёт, другая - за вывод. Если формула изменится, достаточно будет изменить её в `CalculateTotal`, не переписывая код в местах вызова.
