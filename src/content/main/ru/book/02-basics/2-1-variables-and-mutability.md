# 2.1 Переменные и изменяемость

В Cvolo переменные бывают **неизменяемыми** (`val`) и **изменяемыми** (`var`). Изменяемость определяет, можно ли присвоить переменной новое значение после её инициализации. В обоих случаях компилятор может определить тип переменной по начальному значению.

```cvolo
val title = "Hello, Cvolo!";
var attempts = 0;
val ratio = 1.5;
var isReady = false;
```

Здесь объявлены переменные со строковым, целочисленным, дробным и логическим значениями. Их типы не указаны явно - с ними познакомимся в следующей статье.

## Объявление и инициализация

Объявление с выводом типа состоит из ключевого слова `val` или `var`, имени переменной и выражения, задающего начальное значение. Инструкция завершается точкой с запятой.

```cvolo
val start = 10;
var current = start;
```

Переменная `start` инициализируется значением `10`, а `current` - значением `start`. Компилятор определяет тип обеих переменных как `int`.

## `val` - неизменяемые переменные

Ключевое слово `val` используется для объявления **неизменяемой переменной**. После инициализации ей нельзя присвоить новое значение. Попытка изменить такую переменную приводит к ошибке компиляции.

```cvolo tab="Допустимый код" lines
val points = 2;
val nextPoints = points + 1;
```

```cvolo tab="Недопустимый код" lines highlight="2"
val points = 2;
points = 3;
```

Во втором примере компилятор отклонит **строку 2**: переменная `points` объявлена через `val`, поэтому изменить её значение присваиванием нельзя. При этом использовать `points` в вычислениях и инициализировать на её основе другие переменные разрешено.

Неизменяемость не означает, что начальное значение обязательно должно быть известно во время компиляции. Ограничение относится к изменению переменной после инициализации.

## `var` - изменяемые переменные

Ключевое слово `var` используется для объявления **изменяемой переменной**. Её значение можно изменять в процессе выполнения программы, если присваиваемое значение совместимо с типом переменной.

```cvolo
var attempts = 0;
attempts = attempts + 1;

var greeting = "Hello";
greeting = "Hello, Cvolo!";

var isReady = false;
isReady = true;
```

Здесь изменяются значения трёх переменных разных типов: целого числа, строки и логического значения. Их типы при этом остаются прежними.

## Вывод типа

При объявлении через `val` или `var` компилятор выводит тип из выражения инициализации. Изменяемость переменной не влияет на её тип: `var` разрешает присваивать новые значения, но не позволяет произвольно менять тип переменной.

```cvolo tab="Совместимый тип" lines
var count = 2;
count = 3;
```

```cvolo tab="Несовместимый тип" lines highlight="2"
var count = 2;
count = "three";
```

Во втором примере **строка 2** недопустима: переменная `count` имеет тип `int`, а ей пытаются присвоить строку. Компилятор обнаружит несовместимость типов независимо от того, что переменная объявлена через `var`.

Таким образом, `val` выбирают для неизменяемых переменных, а `var` - когда значение потребуется изменять. В следующей статье рассмотрим встроенные типы Cvolo и их особенности.
