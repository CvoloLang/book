# 4.5 Обобщённые типы

Обобщения (generics) позволяют объявлять структуры и функции, **не привязывая их заранее к конкретным типам данных**. Вместо `int`, `string` или другого конкретного типа в объявлении используют **параметр типа**. При использовании структуры или вызове функции на место этого параметра подставляют нужный тип.

Так можно написать одно объявление вместо нескольких почти одинаковых. Например, если нам нужен тип-обёртка с полем `Value`, без обобщений пришлось бы создавать отдельные объявления для числа и строки. С обобщениями достаточно одного.

## Объявление обобщённой структуры

Допустим, нам нужен простой тип, который хранит одно значение. При этом в разных частях программы мы хотим хранить значения разных типов. Объявим обобщённую структуру `Box<T>`:

```cvolo
struct Box<T>
{
    T Value;
}
```

Разберём запись:

- `Box` - имя структуры;
- `<T>` - список **параметров типа** в угловых скобках. Именно он делает объявление обобщённым;
- `T` - параметр типа, который выступает вместо конкретного типа данных;
- `T Value;` - поле `Value`, тип которого будет определён при использовании `Box<T>`.

Здесь `T` **обозначает тип, а не значение**. Пока структура объявлена с параметром `T`, нам не нужно заранее решать, будет ли поле `Value` целым числом, строкой или другим типом.

Имя `T` - распространённое соглашение, а не обязательное ключевое слово. Можно использовать другое допустимое имя, например `TValue`.

## Использование обобщённого типа

При использовании структуры вместо параметра `T` указывают **аргумент типа** - конкретный тип, с которым мы хотим работать:

```cvolo tab="С выводом типа"
var number = Box<int>
{
    Value = 42
};

var message = Box<string>
{
    Value = "Привет"
};
```

```cvolo tab="С указанием типа"
Box<int> number = Box<int>
{
    Value = 42
};

Box<string> message = Box<string>
{
    Value = "Привет"
};
```

В первой вкладке тип переменной выводится из выражения справа от `=`: повторять `Box<int>` или `Box<string>` слева не нужно. Вторая вкладка показывает эквивалентную запись с явным указанием типов.

В `Box<int>` параметр `T` заменён на `int`, поэтому поле `Value` имеет тип `int`. В `Box<string>` он заменён на `string`, и поле `Value` имеет тип `string`.

К полям обращаются так же, как у обычных структур:

```cvolo
int answer = number.Value;
string text = message.Value;
```

**Важно:** `Box<int>` и `Box<string>` - два разных конкретных типа. Обобщение позволяет повторно использовать объявление, но **не означает, что один экземпляр `Box<int>` может хранить значения любых типов**. Аналогично, обычный массив `Box<int>` не может одновременно содержать элементы типа `Box<string>`.

Не путайте две записи:

- `<T>` при объявлении `Box<T>` задаёт *параметр типа*;
- `<int>` или `<string>` при использовании задаёт *аргумент типа*.

## Несколько параметров типа

У структуры может быть больше одного параметра типа. Их перечисляют через запятую:

```cvolo
struct Pair<T, U>
{
    T First;
    U Second;
}
```

В таком объявлении `T` определяет тип поля `First`, а `U` - тип поля `Second`. Эти типы не обязаны совпадать.

```cvolo tab="С выводом типа"
var item = Pair<int, string>
{
    First = 42,
    Second = "Ответ"
};
```

```cvolo tab="С указанием типа"
Pair<int, string> item = Pair<int, string>
{
    First = 42,
    Second = "Ответ"
};
```

У `item.First` тип `int`, а у `item.Second` - `string`. Порядок аргументов типа имеет значение: первый относится к `T`, второй - к `U`.

## Обобщённые объединения

Обобщёнными могут быть не только структуры, но и объединения (`union`). Параметр типа можно использовать для данных одного из вариантов:

```cvolo
union LoadResult<T>
{
    T Data;
    string Error;
}
```

Теперь можно хранить успешный результат загрузки с разными типами данных:

```cvolo tab="С выводом типа"
var number = LoadResult<int>
{
    Data = 42
};

var failure = LoadResult<string>
{
    Error = "Файл не найден"
};
```

```cvolo tab="С указанием типа"
LoadResult<int> number = LoadResult<int>
{
    Data = 42
};

LoadResult<string> failure = LoadResult<string>
{
    Error = "Файл не найден"
};
```

В `LoadResult<int>` вариант `Data` содержит `int`, а в `LoadResult<string>` тот же вариант содержит `string`. Вариант `Error` в обоих случаях остаётся строковым.

Активный вариант обрабатывают обычными способами, уже знакомыми по [разделу 4.3 «Объединения»](4-3-union.md), например через `switch` или `is`.

## Обобщённые функции

Параметры типа поддерживаются также у функций. Они записываются после имени функции:

```cvolo
T Choose<T>(bool first, T a, T b)
{
    if (first)
    {
        return a;
    }

    return b;
}
```

Здесь `T` используется и в типах параметров `a` и `b`, и в возвращаемом типе функции. При вызове указываем конкретный аргумент типа:

```cvolo
var selected = Choose<int>(true, 10, 20);
var price = Choose<double>(false, 1.5, 2.5);
```

Переменная `selected` получает тип `int` и значение `10`, а `price` - тип `double` и значение `2.5`. Для обоих случаев достаточно одного объявления функции.

Обобщённые методы внутри блоков `extension` тоже поддерживаются, но их рассмотрим в [разделе 4.10 «Блоки расширений»](4-10-extension-blocks.md).

## Что важно учитывать

Обобщения не отключают проверку типов. Например, если поле объявлено как `T Value`, то у `Box<int>` оно должно получать значение, совместимое с `int`:

```cvolo
var wrong = Box<int>
{
    Value = "сорок два" // Ошибка: ожидается int, а не string.
};
```

Кроме того, нельзя предполагать, что произвольный тип `T` поддерживает любую операцию. Чтобы разрешать обобщённому коду использовать определённые возможности типов, Cvolo предоставляет ограничения через `where`. Подробно рассмотрим их после знакомства с [интерфейсами (раздел 4.14)](4-14-interfaces.md) и [протоколами (раздел 4.15)](4-15-protocols.md).

## Что дальше

Обобщённые типы позволяют повторно использовать объявления `struct` и `union` с разными аргументами типа. При этом создание, передача и изменение их экземпляров подчиняются тем же правилам владения значениями, что и для других типов.

В следующей статье, [4.6 «Владение, копирование и перемещение»](4-6-ownership.md), разберём, что происходит при передаче таких значений между переменными и функциями.
