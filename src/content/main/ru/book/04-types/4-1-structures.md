# 4.1 Структуры

Структуры (`struct`) позволяют создавать собственные типы данных. Каждый такой тип описывает набор полей, которые будут у его экземпляров.

Представим программу, в которой нужно работать с положением объектов на плоскости. Положение можно задать точкой с двумя координатами - `X` и `Y`. Чтобы использовать эти координаты вместе, создадим тип `Point`.

## Объявление структуры

Структуру объявляют с помощью конструкции `struct`. После неё указывают имя типа, а внутри фигурных скобок - его поля:

```cvolo
struct Point
{
    int X;
    int Y;
}
```

`Point` - имя объявленного типа. Записи `int X;` и `int Y;` задают его поля: `int` обозначает тип поля, а `X` и `Y` - их имена. Значения этих полей будут принадлежать конкретному экземпляру `Point`, а не самому объявлению типа.

Пока мы только определили устройство `Point`. Экземпляр этого типа создадим в следующем разделе.

Поля одной структуры могут иметь разные типы. Например:

```cvolo
struct Player
{
    int Id;
    string Name;
    bool Active;
}
```

Каждое объявление поля заканчивается точкой с запятой.

## Создание экземпляра структуры

Создадим экземпляр `Point` и сохраним его в переменной `point`:

```cvolo
var Point point = Point
{
    X = 10,
    Y = 20
};
```

Разберём запись:

- `var` разрешает изменять переменную.
- `Point` слева от `point` - тип переменной.
- `point` - имя переменной.
- `Point { ... }` справа от `=` - создание экземпляра структуры с указанными значениями полей.

Здесь `var` используется потому, что дальше мы будем менять координаты. В Cvolo переменную можно объявить и без `var`: по умолчанию её нельзя переназначить. При этом запрет на переназначение переменной и запрет на изменение её полей - не одно и то же. К этому различию вернёмся в разделе об обращении к полям.

В фигурных скобках задаём значения полей: `X` получает `10`, а `Y` - `20`.

Имена полей позволяют указать, какому из них соответствует каждое значение. Порядок полей при инициализации не обязан совпадать с порядком их объявления внутри `struct Point`. При такой инициализации в обычном коде требуется указать значения всех полей структуры; пропущенное поле вызовет ошибку компиляции.

### Два способа указать значения полей

В фигурных скобках Cvolo поддерживает два разделителя - `=` и `:`:

```cvolo
var Point first = Point
{
    X = 10,
    Y = 20
};

var Point second = Point
{
    X: 10,
    Y: 20
};
```

Обе записи создают экземпляр `Point` с одинаковыми значениями полей. **Для фигурных скобок предпочтительнее `=`**: такая запись сразу показывает, какие значения получают поля при создании экземпляра. Двоеточие тоже допустимо.

Компилятор допускает и смешанную запись, но для единообразия лучше придерживаться `=`.

### Инициализация в круглых скобках

При объявлении переменной доступна и более короткая форма:

```cvolo
var Point point(X: 10, Y: 20);
```

Тип `Point` здесь указывается один раз, а имена полей и их значения перечисляются в круглых скобках. **В этой форме используется только `:`**. Она напоминает вызов с именованными аргументами (`X: 10`, `Y: 20`), но здесь поля структуры инициализируются напрямую, без вызова конструктора.

Конструкторы - другой способ задавать начальное состояние экземпляра. Их объявление и использование рассматриваются в разделе [4.10 «Конструкторы»](4-10-constructors.md).

## Обращение к полям

Чтобы обратиться к полю экземпляра, используют точку:

```cvolo
int x = point.X;
int y = point.Y;
```

Переменная `point` объявлена с `var`, поэтому можно изменять и её поля:

```cvolo
point.X = 15;
point.Y = 25;
```

Теперь `point.X` равно `15`, а `point.Y` - `25`.

**Объявление без `var` запрещает переназначить переменную, но само по себе не запрещает изменять поля структуры.** Например:

```cvolo
Point target = Point
{
    X = 0,
    Y = 0
};

target.X = 10; // Допустимо: поле можно изменить.
```

Если же нужно явно запретить изменение полей через переменную, используют `val`:

```cvolo
val Point origin = Point
{
    X = 0,
    Y = 0
};

origin.X = 30; // Ошибка: изменение поля через val запрещено.
```

Подробнее о передаче значений, изменяемости и ссылках рассказывается в разделах [4.5 «Владение, копирование и перемещение»](4-5-ownership.md) и [4.6 «Ссылки и заимствование»](4-6-references.md).
