# Cvolo: краткий справочник по языку

Cvolo — **компилируемый системный язык программирования** с C#-подобной синтаксической эргономикой, детерминированной безопасностью памяти на этапе компиляции и нативной генерацией кода через LLVM.

Этот раздел — не учебник по порядку глав. Здесь каждая страница отвечает на конкретный вопрос: что означает конструкция, какие у неё правила, когда она доступна и как она связана с остальной моделью языка.

## Что такое Cvolo

Минимальная hosted-программа выглядит так:

```cvolo
using System;

int main() {
    Console.WriteLine("Hello, Cvolo!");
    return 0;
}
```

В этом примере одновременно видны три разных слоя:

| Слой | Что относится к нему |
|---|---|
| язык | `int`, функция `main`, `return`, блоки, `using` |
| Base SDK | `Option<T>`, `Result<T, E>`, `Type`, compiler-known attributes |
| System | `Console` и другие hosted API стандартной библиотеки |

> [!NOTE]
> Base и System — не одно и то же. Base присутствует всегда и не является namespace. System подключается по фактическим импортам программы.

## Основные идеи языка

Cvolo делает важные свойства видимыми прямо в коде:

```cvolo
int readOnly = 10;
var int counter = 0;

ref Point point = ref source;
refvar Point editable = ref source;
```

- обычное объявление с типом создаёт неизменяемое значение;
- `var` разрешает изменение локального значения;
- `ref T` — безопасная read-only ссылка;
- `refvar T` — безопасная изменяемая ссылка;
- отсутствие значения в safe-коде моделируется через `Option<T>` / `T?`, а не через сырой `null`;
- recoverable error моделируется через result-shape, обычно `Result<T, E>`;
- raw pointers, hardware `null` и ABI-операции находятся в `unsafe`.

## Как устроена документация

На сайте три уровня информации:

1. **Учебник** — последовательное изучение языка от первой программы до FFI.
2. **Документация** — справочные страницы в стиле language reference: определение, формы синтаксиса, примеры и важные детали реализации.
3. **Спецификация** — формальные контракты: lowering, layout, result-shapes, правила разрешения Base/System и другие точные инварианты.

Если вы впервые встречаете конструкцию, начинайте с учебника. Если уже знаете, что ищете, открывайте документацию. Для деталей компиляции и формальных ограничений переходите в спецификацию.
