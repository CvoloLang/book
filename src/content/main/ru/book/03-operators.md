# Глава 3. Операторы

Операторы Cvolo близки к C/C#/C++ и не скрывают дополнительные преобразования типов.

## 3.1 Арифметика и присваивание

```cvolo
var int a = 10;
var int b = 3;

int sum = a + b;
int diff = a - b;
int product = a * b;
int quotient = a / b;
int remainder = a % b;
```

Для изменяемых значений доступны составные присваивания:

```cvolo
var int x = 10;
x += 5;
x *= 2;
x--;
```

## 3.2 Сравнение и логика

```cvolo
bool same = a == b;
bool different = a != b;
bool inside = a >= 0 && a < 100;
bool outside = !inside;
```

`&&` и `||` используют short-circuit evaluation: правая часть вычисляется только если она действительно нужна.

## 3.3 Побитовые операции и разрядность целых

### Побитовые операции

Для целых типов доступны:

```cvolo
uint a = 0b1010U;
uint b = 0b1100U;

uint andValue = a & b;
uint orValue = a | b;
uint xorValue = a ^ b;
uint inverted = ~a;
uint shifted = a << 2;
```

Также доступны `>>` и логический сдвиг `>>>`, а для изменяемых значений — `&=`, `|=`, `^=`, `<<=`, `>>=` и `>>>=`.

### Узкие целые типы

Cvolo специально сохраняет ширину операций над `byte`, `sbyte`, `short` и `ushort`. Компилятор не должен молча расширять каждую такую операцию до 32 бит.

```cvolo
byte a = 0xF0;
byte b = 0x0F;
byte c = a | b;
```

Для системного кода это означает более предсказуемые правила переполнения, масок и layout.
