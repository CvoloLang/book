# 3.4 Конструкция `switch`

В [разделе 3.1](3-1-if-and-else.md) мы познакомились с `if` и `else`, которые позволяют выполнять код в зависимости от логического условия. Но иногда выбор должен зависеть не от отдельной проверки, а от того, **какой вариант имеет значение**. Для этого в Cvolo предусмотрена конструкция `switch`.

## Какие типы поддерживаются

В текущей версии Cvolo `switch` работает с **перечислениями (`enum`)** и **объединениями (`union`)**. Эти типы позволяют представить значение как один из заранее определённых вариантов.

В отличие от некоторых других языков, **обычные числа, например `int`, пока нельзя использовать непосредственно в `switch`**. Такой код не пройдёт компиляцию:

```cvolo
using System;

int main()
{
    int number = 2;

    switch (number)
    {
        default:
            Console.WriteLine("Other");
    }

    return 0;
}
```

Для выбора действий по числовому значению используйте `if`, `else if` и `else`, о которых мы говорили в [разделе 3.1](3-1-if-and-else.md).

## Как устроен `switch`

Конструкция `switch` выбирает подходящую ветвь `case` по варианту перечисления или объединения. Ветвь `default` (или `case _`) обрабатывает остальные варианты. В Cvolo после выполнения выбранной ветви **нет автоматического перехода к следующему `case`**, поэтому добавлять `break;` в конце каждой ветви не требуется.

Подробные примеры `switch`, проверку всех вариантов и работу с данными внутри `union` мы рассмотрим в статьях о **перечислениях** и **объединениях**, после знакомства с пользовательскими типами.
