# 3.2 Циклы `for` и `while`

Иногда программе нужно выполнить одни и те же инструкции несколько раз. Например, вывести числа от `0` до `4`, обработать несколько значений или повторять проверку, пока не будет получен нужный результат.

Для этого существуют **циклы**. Они позволяют повторять блок кода, пока выполняется заданное условие. Одно выполнение тела цикла называется **итерацией**.

В Cvolo для таких задач используются циклы `for` и `while`. Оба проверяют условие перед выполнением тела, но отличаются тем, как в них записывают управление повторениями.

## Цикл `for`

Цикл `for` удобен, когда нужно повторить действие определённое количество раз или последовательно изменять счётчик.

Рассмотрим программу, которая выводит три числа:

```cvolo
using System;

int main()
{
    for (var i = 0; i < 3; i++)
    {
        Console.WriteLine(i);
    }

    Console.WriteLine("Done");
    return 0;
}
```

```output
0
1
2
Done
```

В круглых скобках после `for` находятся три части, разделённые точками с запятой:

- `var i = 0` - **инициализация**. Создаёт изменяемую переменную `i` со значением `0`. Эта часть выполняется один раз, перед началом цикла.
- `i < 3` - **условие продолжения**. Перед каждой итерацией программа проверяет, меньше ли `i` числа `3`. Пока условие равно `true`, тело цикла выполняется.
- `i++` - **изменение счётчика**. После выполнения тела увеличивает значение `i` на единицу.

### Как выполняется `for`

Разберём выполнение по порядку:

1. Создаётся переменная `i` со значением `0`.
2. Проверяется `i < 3`. Условие истинно, поэтому программа выводит `0`.
3. Выполняется `i++`, и значение `i` становится равным `1`.
4. Условие проверяется снова. Программа выводит `1`, затем `2` при следующих итерациях.
5. Когда `i` становится равным `3`, условие `i < 3` возвращает `false`, и цикл завершается.

После этого выполняется инструкция за пределами цикла, которая выводит `Done`.

Обратите внимание: цикл выводит числа `0`, `1` и `2`, **но не `3`**. Оператор `<` проверяет строгое неравенство. Если бы мы использовали `i <= 3`, число `3` тоже было бы выведено.

Для счётчика используется `var`, поскольку его значение изменяется. Запись `i++` увеличивает `i` на единицу. Операторы `++` и `--` подробно рассмотрены в разделе [2.6 «Присваивание и изменение значения»](../02-basics/2-6-assignment.md).

## Цикл `while`

Цикл `while` выполняет блок кода **пока условие истинно**. В отличие от `for`, в круглых скобках после `while` записывается только условие. Если нужен счётчик, его объявление и изменение указывают отдельно.

Та же программа с циклом `while` выглядит так:

```cvolo
using System;

int main()
{
    var i = 0;

    while (i < 3)
    {
        Console.WriteLine(i);
        i++;
    }

    Console.WriteLine("Done");
    return 0;
}
```

```output
0
1
2
Done
```

Сначала создаётся переменная `i`. Перед каждой итерацией проверяется `i < 3`. Если условие равно `true`, программа выводит текущее значение и увеличивает `i`. Затем возвращается к проверке условия.

Когда `i` достигает значения `3`, условие становится ложным и выполнение продолжается после цикла.

**Важное отличие:** в `while` изменение переменной не является частью заголовка цикла. За него отвечает код внутри тела. Если забыть `i++`, значение `i` останется равным `0` и условие `i < 3` никогда не станет ложным. Такой цикл будет повторяться бесконечно, если его выполнение не прервётся по другой причине.

## Проверка условия перед первой итерацией

И `for`, и `while` проверяют условие **до первой итерации**. Поэтому тело цикла может вообще не выполниться.

```cvolo
using System;

int main()
{
    var count = 0;

    while (count > 0)
    {
        Console.WriteLine("Inside loop");
        count--;
    }

    Console.WriteLine("Done");
    return 0;
}
```

```output
Done
```

Значение `count` равно `0`, поэтому условие `count > 0` изначально ложно. Программа сразу переходит к инструкции после цикла. Аналогично работает `for`, если его условие ложно при первой проверке.

Как и в `if`, условие цикла должно возвращать значение типа `bool`. Например, `while (count > 0)` допустимо, а `while (count)` при типе `int` вызовет ошибку компиляции.

## Область видимости счётчика

Переменная, объявленная в заголовке `for`, доступна внутри этого цикла, но не за его пределами:

```cvolo tab="Допустимо"
for (var i = 0; i < 3; i++)
{
    Console.WriteLine(i);
}
```

```cvolo tab="Недопустимо" lines highlight="6"
for (var i = 0; i < 3; i++)
{
    Console.WriteLine(i);
}

Console.WriteLine(i); // i больше не доступна
```

В примере с `while` переменная `i` объявлена **перед циклом**, поэтому она остаётся доступной и после его завершения.

Переменные, которые объявлены непосредственно внутри фигурных скобок тела цикла, также принадлежат этому блоку. Подробнее об областях видимости - в разделе [2.9 «Функции»](../02-basics/2-9-functions.md).

## Пример: сумма первых пяти чисел

Применим цикл `for` для вычисления суммы чисел от `1` до `5`:

```cvolo
using System;

int main()
{
    var total = 0;

    for (var number = 1; number <= 5; number++)
    {
        total = total + number;
    }

    Console.WriteLine(total);
    return 0;
}
```

```output
15
```

Перед началом цикла переменная `total` равна `0`. На каждой итерации к ней прибавляется текущее значение `number`. Последовательно получаются суммы `1`, `3`, `6`, `10` и `15`. После пятой итерации `number` становится равным `6`, условие `number <= 5` оказывается ложным, и программа выводит результат.

Таким образом, `for` и `while` позволяют выполнять одни и те же инструкции многократно без повторения их в исходном коде. В следующем разделе мы познакомимся с инструкциями `break` и `continue`, которые позволяют досрочно завершать цикл или переходить к следующей итерации.
