# 3.3 Управление циклами: `break` и `continue`

В предыдущей статье мы научились повторять действия с помощью циклов `for` и `while`. Обычно цикл завершается, когда его условие становится ложным. Но бывают ситуации, когда цикл нужно **завершить по дополнительному условию** или **пропустить оставшиеся инструкции текущей итерации**.

В Cvolo для этого используются инструкции `break` и `continue`.

## Досрочный выход с помощью `break`

Инструкция `break;` немедленно завершает выполнение ближайшего цикла. Программа продолжает работу с первой инструкции после него.

Предположим, мы перебираем числа от `0` до `5`, но хотим остановиться, когда встретим `3`:

```cvolo
using System;

int main()
{
    for (var i = 0; i < 6; i++)
    {
        if (i == 3)
        {
            break;
        }

        Console.WriteLine(i);
    }

    Console.WriteLine("Done");
    return 0;
}
```

```output
0
1
2
Done
```

При `i == 3` условие внутри `if` становится истинным, и выполняется `break;`. До `Console.WriteLine(i)` программа уже не доходит. Цикл завершается, а инструкция после него выводит `Done`.

`break` можно использовать и в цикле `while`. При этом не важно, какое значение имеет условие самого цикла: если выполняется `break;`, повторения прекращаются сразу.

## Переход к следующей итерации с `continue`

Инструкция `continue;` не завершает весь цикл. Вместо этого она **пропускает оставшиеся инструкции текущей итерации** и переходит к следующему повторению.

Например, выведем только нечётные числа:

```cvolo
using System;

int main()
{
    for (var i = 0; i < 6; i++)
    {
        if (i % 2 == 0)
        {
            continue;
        }

        Console.WriteLine(i);
    }

    return 0;
}
```

```output
1
3
5
```

Операция `i % 2` возвращает остаток от деления на `2`. Если остаток равен `0`, число чётное. В таком случае `continue;` пропускает вывод и передаёт управление следующей итерации.

**Важно:** в цикле `for` после `continue;` выполняется часть заголовка, отвечающая за изменение счётчика (`i++`), и только затем снова проверяется условие. Поэтому в этом примере цикл не застревает на чётных числах.

### `continue` в цикле `while`

В `while` нет отдельной части заголовка для изменения счётчика. Поэтому необходимо учитывать, где находится `continue;`.

```cvolo
using System;

int main()
{
    var i = 0;

    while (i < 5)
    {
        i++;

        if (i == 3)
        {
            continue;
        }

        Console.WriteLine(i);
    }

    return 0;
}
```

```output
1
2
4
5
```

Значение `i` увеличивается **до** проверки `i == 3`. Если срабатывает `continue;`, программа возвращается к условию `while (i < 5)` уже с обновлённым счётчиком.

Если разместить `i++` только в конце тела после `continue;`, при определённых условиях счётчик перестанет изменяться и цикл может стать бесконечным.

## `break` и `continue` во вложенных циклах

Один цикл может находиться внутри другого. Без дополнительных указаний `break;` и `continue;` действуют на **ближайший цикл**.

```cvolo
using System;

int main()
{
    for (var row = 0; row < 3; row++)
    {
        for (var column = 0; column < 3; column++)
        {
            if (column == 1)
            {
                break;
            }

            Console.WriteLine(row * 10 + column);
        }
    }

    return 0;
}
```

```output
0
10
20
```

Когда `column` становится равным `1`, инструкция `break;` завершает **внутренний** цикл. Внешний цикл продолжает работать и переходит к следующему значению `row`.

Если вместо `break;` использовать `continue;`, пропускаться будет только остаток текущей итерации внутреннего цикла.

## Метки циклов

Иногда из внутреннего цикла нужно выйти сразу из внешнего или перейти к его следующей итерации. В Cvolo перед циклом можно поставить **метку** - имя с двоеточием:

```cvolo
outer: for (var row = 0; row < 3; row++)
{
    // Тело цикла
}
```

Теперь в инструкциях `break` и `continue` можно указать эту метку.

### `break` с именем цикла

```cvolo
using System;

int main()
{
    outer: for (var row = 0; row < 3; row++)
    {
        for (var column = 0; column < 3; column++)
        {
            if (row == 1 && column == 1)
            {
                break outer;
            }

            Console.WriteLine(row * 10 + column);
        }
    }

    Console.WriteLine("Done");
    return 0;
}
```

```output
0
1
2
10
Done
```

`break outer;` завершает **весь внешний цикл `outer`**, даже если инструкция находится внутри другого цикла.

### `continue` с именем цикла

```cvolo
using System;

int main()
{
    outer: for (var row = 0; row < 3; row++)
    {
        for (var column = 0; column < 3; column++)
        {
            if (column == 1)
            {
                continue outer;
            }

            Console.WriteLine(row * 10 + column);
        }
    }

    return 0;
}
```

```output
0
10
20
```

При `column == 1` инструкция `continue outer;` завершает текущую итерацию внешнего цикла. В случае `for` после этого выполняется изменение счётчика `row++`, затем проверяется условие `row < 3`.

Метки особенно полезны во вложенных циклах: они позволяют явно указать, **каким именно циклом** нужно управлять.

## Чем `break` и `continue` отличаются от `return`

Мы уже использовали `return`, когда изучали функции. Эти инструкции влияют на выполнение по-разному:

| Инструкция | Что происходит |
| --- | --- |
| `break;` | Завершается ближайший цикл. |
| `continue;` | Пропускается остаток текущей итерации ближайшего цикла. |
| `return;` | Завершается выполнение всей текущей функции. |
