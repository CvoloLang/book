# 3.1 Условные конструкции `if` и `else`

**Условная конструкция `if`** позволяет выполнять определённый код в зависимости от заданного условия.

Вы указываете условие и блок кода, который необходимо выполнить. Если условие истинно (`true`), программа выполняет этот блок. Если условие ложно (`false`), блок пропускается и программа продолжает выполнение.

При необходимости можно указать альтернативные действия с помощью `else`.

## Конструкция `if`

В Cvolo условная конструкция записывается как `if (Условие)`, после чего указывают инструкцию или блок кода в фигурных скобках.

Рассмотрим пример, в котором программа проверяет, разрешён ли пользователю доступ. Во второй инструкции после `if` специально оставлен дополнительный вывод, чтобы было наглядно видно, продолжает ли программа выполнение после условного блока.

```cvolo tab="hasAccess = true"
using System;

int main()
{
    bool hasAccess = true;

    if (hasAccess)
    {
        Console.WriteLine("Access granted");
    }

    Console.WriteLine("Done");
    return 0;
}
```

```output tab="hasAccess = true"
Access granted
Done
```

```cvolo tab="hasAccess = false"
using System;

int main()
{
    bool hasAccess = false;

    if (hasAccess)
    {
        Console.WriteLine("Access granted");
    }

    Console.WriteLine("Done");
    return 0;
}
```

```output tab="hasAccess = false"
Done
```

Здесь:

- `if` - ключевое слово, начинающее условную конструкцию;
- `(hasAccess)` - **условие**, результатом которого должно быть значение типа `bool`;
- `{` и `}` - границы блока кода, который выполняется, только если условие равно `true`.

В первой вкладке `hasAccess` равно `true`, поэтому программа выполняет блок `if` и выводит `Access granted`. Во второй вкладке `hasAccess` равно `false`, поэтому этот блок пропускается. При этом в обоих случаях программа продолжает выполнение после `if`, и поэтому строка `Done` выводится всегда.

Условием может быть не только готовая переменная типа `bool`, но и выражение, например результат сравнения `score >= 60`. Операции сравнения и логические выражения мы разбирали в разделе [2.5 «Сравнения и логические выражения»](../02-basics/2-5-comparisons-and-logic.md).

## Ветвление с `else`

Конструкция `if` позволяет выполнить действие при истинном условии. Если требуется указать, что делать при ложном условии, используют `else`:

```cvolo
int temperature = 12;

if (temperature >= 18)
{
    Console.WriteLine("Warm");
}
else
{
    Console.WriteLine("Cool");
}
```

Если условие `temperature >= 18` равно `true`, выполняется первый блок. В противном случае выполняется блок после `else`. **За один проход выполняется только одна из этих двух ветвей.**

Ключевое слово `else` не содержит собственного условия: оно обозначает альтернативную ветвь предыдущего `if`.

## Несколько условий с `else if`

Когда возможных вариантов больше двух, можно последовательно проверить несколько условий с помощью `else if`:

```cvolo
int score = 75;

if (score >= 90)
{
    Console.WriteLine("Excellent");
}
else if (score >= 60)
{
    Console.WriteLine("Passed");
}
else
{
    Console.WriteLine("Failed");
}
```

Программа проверяет условия **сверху вниз**:

1. Если `score >= 90`, выводится `Excellent`, а остальные ветви пропускаются.
2. Иначе проверяется `score >= 60`. Если оно истинно, выводится `Passed`.
3. Если ни одно условие не выполнено, выводится `Failed`.

Поскольку `score` равно `75`, программа выведет `Passed`.

Порядок условий имеет значение. Если бы сначала проверялось `score >= 60`, то для результата `95` выполнилась бы эта ветвь, а проверка `score >= 90` уже не произошла бы.

В Cvolo `else if` - это сочетание `else` и следующего `if`, а не отдельное ключевое слово.

## Условие должно иметь тип `bool`

Cvolo требует, чтобы выражение в круглых скобках после `if` имело тип `bool`: `true` или `false`. Само число, даже ненулевое, нельзя использовать вместо логического значения.

```cvolo tab="Допустимо"
int count = 3;

if (count > 0)
{
    Console.WriteLine("Items found");
}
```

```cvolo tab="Недопустимо" lines highlight="3"
int count = 3;

if (count)
{
    Console.WriteLine("Items found");
}
```

В первом случае выражение `count > 0` возвращает `bool`. Во втором `count` имеет тип `int`, поэтому компилятор сообщает об ошибке.

Не путайте `=` и `==`: первый оператор присваивает значение, а второй сравнивает два значения. В качестве условия `if` требуется выражение с логическим результатом, а не присваивание.

## Вложенные условия и блоки кода

Внутри одного условного блока можно разместить другой `if`. Такие конструкции называются **вложенными**:

```cvolo
bool isAuthenticated = true;
bool isAdmin = false;

if (isAuthenticated)
{
    if (isAdmin)
    {
        Console.WriteLine("Admin panel");
    }
    else
    {
        Console.WriteLine("User panel");
    }
}
else
{
    Console.WriteLine("Sign in required");
}
```

Сначала проверяется, вошёл ли пользователь в систему. Только если первая проверка пройдена, программа проверяет административные права. В этом примере будет выведено `User panel`.

Обратите внимание: внутренний `else` относится к внутреннему `if (isAdmin)`, а внешний - к `if (isAuthenticated)`.

В Cvolo после `if` и `else` допускается одна инструкция без фигурных скобок. Однако **для читаемости лучше использовать `{` и `}`**, особенно при вложенных условиях.

Переменные, объявленные внутри блока `{ ... }`, принадлежат его области видимости и недоступны за пределами этого блока. О локальных переменных мы говорили в разделе [2.9 «Функции»](../02-basics/2-9-functions.md).

## Тернарный оператор `?:`

Когда нужно **выбрать одно из двух значений**, а не выполнить разные блоки инструкций, удобно использовать **тернарный оператор**:

`Условие ? ЗначениеЕслиИстина : ЗначениеЕслиЛожь`

```cvolo
int first = 10;
int second = 17;

int maximum = first > second ? first : second; // 17
```

Сначала вычисляется `first > second`. Если результат равен `true`, всё выражение принимает значение `first`, иначе - `second`. В `maximum` сохраняется `17`.

В отличие от `if`, тернарный оператор `?:` **сам является выражением**, результат которого можно присвоить переменной или использовать в другом выражении. Ветви `?:` должны иметь совместимые типы; при обычном использовании в Cvolo компилятор требует, чтобы их типы совпадали.

Если для каждого варианта нужно выполнить несколько инструкций, обычно понятнее использовать `if` и `else`.

## Пример: проверка результата экзамена

Объединим несколько условий в одной функции. Программа проверяет, находится ли оценка в допустимом диапазоне, и выводит соответствующее сообщение.

```cvolo
using System;

void PrintResult(int score)
{
    if (score < 0 || score > 100)
    {
        Console.WriteLine("Invalid score");
        return;
    }

    if (score >= 90)
    {
        Console.WriteLine("Excellent");
    }
    else if (score >= 60)
    {
        Console.WriteLine("Passed");
    }
    else
    {
        Console.WriteLine("Failed");
    }
}

int main()
{
    PrintResult(95);
    PrintResult(75);
    PrintResult(40);
    PrintResult(-5);

    return 0;
}
```

```output
Excellent
Passed
Failed
Invalid score
```

Сначала функция проверяет, допустимо ли значение `score`. Если оно меньше `0` или больше `100`, выводится сообщение `Invalid score`, а `return;` **сразу завершает функцию**. Остальные проверки не выполняются.

Если оценка допустима, программа последовательно проверяет условия и выбирает первую подходящую ветвь. Подробнее о `return` и функциях - в разделе [2.9 «Функции»](../02-basics/2-9-functions.md).
