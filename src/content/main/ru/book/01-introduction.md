# Глава 1. Введение в Cvolo

Cvolo — компилируемый системный язык с синтаксисом, близким к C#-подобным языкам, и явными правилами владения, ссылок и мутабельности. Эта глава — первый маршрут по языку: как выглядит программа, как подключается стандартная библиотека и куда двигаться дальше.

Учебник сосредоточен на публичном синтаксисе и коде, который пишет пользователь. Когда тема требует точной модели компиляции, стоимости абстракции или lowering, страница учебника ссылается на **Продвинутую книгу**. Примитивы, доступные всегда, описаны в **Base**, а hosted API — в **Std / System**.

## 1.1 Первая программа

Для консольного вывода используется `System.Console`, поэтому обычная hosted-программа сначала импортирует namespace `System`:

```cvolo
using System;

int main() {
    Console.WriteLine("Hello, Cvolo!");
    return 0;
}
```

Для исполняемого target точкой входа служит функция `int main()`. Она возвращает код завершения процесса, поэтому каждый путь выполнения должен завершиться значением `int`.

**Что здесь важно:**

- `using System;` подключает поверхность стандартной библиотеки `System` к этому исходному файлу и позволяет использовать её имена без полного префикса;
- `int` — 32-битный знаковый целый тип;
- `main()` — точка входа executable-программы;
- `Console.WriteLine(...)` печатает строку в консоль;
- блок функции заключается в `{ ... }`;
- в `main` выражение `return 0;` возвращает host-среде код завершения процесса `0`; в обычной функции `return` возвращает значение вызывающему коду.

## 1.2 `using System;` и стандартная библиотека

`using` в Cvolo — это импорт namespace, а не текстовая вставка другого файла. Для стандартной библиотеки он также выступает корнем зависимости: компилятор подключает нужные части System, до которых доходит программа, а не обязан загружать всю библиотеку целиком.

Обычная форма:

```cvolo
using System;

int main() {
    Console.WriteLine("hello");
    return 0;
}
```

Без `using` можно обратиться к тому же API полным именем:

```cvolo
int main() {
    System.Console.WriteLine("hello");
    return 0;
}
```

При этом сам язык и **Base SDK** доступны без `using System;`. Например, программа, которая не использует hosted API, не обязана импортировать `System`:

```cvolo
int main() {
    return 0;
}
```

Не путайте `using` с `include`: `using` работает с именами и зависимостями API, а `include` используется при сборке многофайлового module и физически включает исходный файл в module scope. Подробнее это разобрано в главе о модулях. Отдельно устройство SDK разобрано в главах [Base SDK](18-base-sdk.md) и [System](19-system-standard-library.md). Справочное определение слоёв доступно в [справочнике Base](../base/01-base.md) и [документации System](../std/01-system.md).

## 1.3 Общий стиль языка

Cvolo делает несколько правил видимыми прямо в синтаксисе:

```cvolo
int readOnly = 10;      // неизменяемое значение
var int counter = 0;    // изменяемое значение
val inferred = 42;      // int, только чтение
var dynamicCount = 4;   // int, можно менять
```

Обычное объявление с типом неизменяемо. Для изменения значения используется `var`. Для вывода типа можно использовать `val` или `var`.

Такой стиль распространяется и на ссылки: `ref` означает доступ только для чтения, а `refvar` — изменяемую ссылку.

## 1.4 Как читать учебник

Рекомендуемый порядок:

1. типы, переменные и литералы;
2. операторы и управляющие конструкции;
3. функции;
4. структуры и `extension`;
5. массивы и slices;
6. `Option<T>`, ссылки и правила памяти;
7. интерфейсы, делегаты и модули;
8. обработка ошибок, `defer`, unsafe и FFI.

Учебные главы намеренно не перегружают текст деталями compiler lowering. Для точной модели компиляции и стоимости абстракций переходите по ссылкам в Продвинутую книгу; библиотечные контракты вынесены в Base и Std / System.
