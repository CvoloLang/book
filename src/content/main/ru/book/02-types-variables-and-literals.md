# Глава 2. Типы данных, переменные и литералы

Большая часть кода в Cvolo начинается с простых значений: чисел, `bool`, символов и строк. Главное отличие от многих C-подобных языков — неизменяемость по умолчанию.

## 2.1 Примитивные типы

Основные встроенные типы:

| Тип | Назначение |
|---|---|
| `int`, `uint` | 32-битные целые |
| `long`, `ulong` | 64-битные целые |
| `short`, `ushort` | 16-битные целые |
| `byte`, `sbyte` | 8-битные целые |
| `float`, `double` | числа с плавающей точкой |
| `bool` | `true` / `false` |
| `char` | символ |
| `string` | строка UTF-8 |
| `void` | отсутствие возвращаемого значения |

```cvolo
int score = 120;
uint mask = 0xFFU;
long ticks = 10_000_000L;
double ratio = 0.25;
bool ready = true;
char letter = 'C';
string title = "Cvolo";
```

Для системного кода важен физический размер типа: язык не должен незаметно превращать `byte` или `short` в `int` во время арифметики.

## 2.2 Переменные и изменяемость

### Неизменяемость и `var`

Переменная с явным типом считается read-only:

```cvolo
int width = 1920;
// width = 1280; // ошибка: width неизменяем
```

Чтобы разрешить присваивание, добавьте `var`:

```cvolo
var int width = 1920;
width = 1280;
```

Это правило полезно читать буквально: если в коде нет `var`, значение не должно неожиданно меняться.

### Вывод типа: `val` и `var`

`val` выводит тип и оставляет значение неизменяемым. `var` без явного типа выводит тип и создаёт изменяемую переменную.

```cvolo
val count = 10;       // int, только чтение
var index = 0;        // int, изменяемый
val distance = 2.5;   // double
val timeout = 500L;   // long
val flags = 7UL;      // ulong
```

Обычный целочисленный литерал выводится как `int`, десятичный литерал — как `double`. Для других целых типов используются суффиксы `U`, `L`, `UL`/`LU`.

## 2.3 Литералы, символы и строки

### Числовые литералы

Cvolo поддерживает десятичные, шестнадцатеричные и двоичные литералы, а `_` можно использовать как визуальный разделитель.

```cvolo
int million = 1_000_000;
uint color = 0xFF_00_FFU;
uint bits = 0b1010_1111U;
ulong addressMask = 0xDEAD_BEEF_CAFE_1234UL;
```

Для floating-point доступны суффиксы `F`/`f` и `D`/`d`:

```cvolo
float a = 1.0f;
double b = 2.5D;
float c = 3.14e10F;
```

### Символы и escape-последовательности

```cvolo
char newline = '\n';
char tab = '\t';
char zero = '\0';
char letter = 'W';
char hex = '\x41';
```

`\x41` соответствует символу `A`.

### Строки

Обычная строка использует escape-последовательности:

```cvolo
string path = "C:\\deps\\win";
```

Raw-строка начинается с `@`:

```cvolo
string path = @"C:\deps\win";
string quote = @"He said ""hi""";
```

Интерполяция использует `$`:

```cvolo
string name = "world";
Console.WriteLine($"Hello, {name}!");
Console.WriteLine(@$"Path: C:\users\{name}");
```

Динамическое соединение строк через `+` не является универсальным runtime-механизмом: для compile-time строк допустима конкатенация, а для значений времени выполнения используйте интерполяцию.
